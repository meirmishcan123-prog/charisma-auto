# מקרו רובלוקס לחציבת עצים 🌳🪓 (תנועה אוטומטית)

> 🟢 **הכי פשוט:** לחץ פעמיים על **`ROBLOX-TREE-MACRO.bat`** — קובץ אחד שמתקין
> הכל לבד ומריץ. אחר כך בתוך המשחק: **F6** להתחיל, **F8** לצאת.

במשחק חוצבים עץ ע"י התקרבות אליו — הדמות חוצבת אוטומטית את העץ שהיא לידו.
לכן המקרו **מזיז את הדמות בשדה בעזרת מקשי התנועה W/A/S/D**, כך שהיא עוברת בין
כל העצים וחוצבת אותם ברצף.

## הפעלה ידנית (למי שמעדיף)
```bash
pip install pynput
python tree_macro.py                 # ברירת מחדל: patrol (תבנית ריבוע)
python tree_macro.py --mode random   # הליכה אקראית
python tree_macro.py --step 0.9      # שניות להחזיק כל כיוון (איטי/מהיר)
python tree_macro.py --keys arrows   # להשתמש בחיצים במקום WASD
```

## מקשי קיצור בזמן ריצה
| מקש | פעולה |
|-----|-------|
| **F6** | התחל / עצור |
| **F8** | יציאה |

## מצבי תנועה
- **patrol** (ברירת מחדל) — הדמות הולכת בתבנית ריבוע: קדימה, ימינה, אחורה,
  שמאלה, וחוזר. מסודר ומכסה את השדה.
- **random** — הליכה אקראית עם אלכסונים. מכסה שטח יפה ולא נתקע בפינה.

## טיפים
- הדמות "בורחת" מהעצים? הקטן את `--step` (למשל 0.5) לצעדים קצרים יותר.
- לא מתקרבת מספיק? נסה `--mode random` שמכסה יותר שטח.
- ודא שחלון רובלוקס בפוקוס לפני שלוחצים F6 (אחרת המקשים לא מגיעים למשחק).
