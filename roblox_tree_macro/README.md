# מקרו רובלוקס לחציבת עצים 🌳🪓

תוכנת פייטון שחוצבת עצים אוטומטית במשחקי "טאפ / חציבה" ברובלוקס (כמו
Tree Tapping / Wood Cutting Simulator). המקרו לוחץ בשבילך על העצים, בשתי שיטות.

> ⚠️ זהו כלי אוטומציה מקומי בלבד (מדמה לחיצות עכבר). הוא לא נוגע בקבצי המשחק
> ולא משנה אותו. שים לב לכללי השירות של המשחק/רובלוקס לפני שימוש.

## התקנה

צריך פייטון 3.8 ומעלה.

```bash
cd roblox_tree_macro
pip install -r requirements.txt
```

## הפעלה

```bash
python tree_macro.py                 # מצב זיהוי עצים (detect) – ברירת מחדל
python tree_macro.py --mode spam     # מצב לחיצה מהירה במיקום קבוע
python tree_macro.py --cps 14        # 14 לחיצות בשנייה
```

## מקשי קיצור בזמן ריצה

| מקש | פעולה |
|-----|-------|
| **F6** | התחל / עצור את המקרו |
| **F7** | קבע מיקום לחיצה (רק במצב `spam`) – הזז את העכבר על העץ/כפתור ולחץ F7 |
| **F8** | יציאה מהתוכנה |
| עכבר לפינה שמאלית-עליונה | עצירת חירום מיידית (FailSafe) |

## שתי השיטות

### 1. מצב זיהוי (`detect`) – מומלץ
סורק את המסך, מזהה עצים לפי הצבע הירוק/צהוב הבהיר שלהם, ולוחץ עליהם ישירות
אחד-אחרי-השני. אם רוצים לצמצם את אזור הסריקה רק למגרש (מהיר ומדויק יותר):

```bash
python tree_macro.py --mode detect --region 500,250,900,550
```
`--region` מקבל `left,top,width,height` בפיקסלים.

### 2. מצב לחיצה מהירה (`spam`) – הכי אמין
לוחץ שוב-ושוב במיקום אחד קבוע. שימושי אם במשחק מספיק ללחוץ במרכז המגרש או
על כפתור. הרצה:
```bash
python tree_macro.py --mode spam
```
אחר כך הזז את העכבר למקום הרצוי ולחץ **F7** כדי לקבע אותו, ו-**F6** להתחיל.

## טיפים לכיוונון
- **הצבעים לא מזהים טוב?** אפשר לשנות את הסף בפונקציה `find_tree_targets`
  בקובץ `tree_macro.py` (המשתנים `green` ו-`yellow`).
- **המקרו לוחץ על ה-UI במקום העצים?** השתמש ב-`--region` כדי להגביל את הסריקה
  רק לאזור המגרש (החלק החום/הקרקע במרכז).
- **קצב לחיצות:** התחל ב-`--cps 8` והעלה בהדרגה. קצב גבוה מדי יכול "להיבלע".
